## 准备

### 账号相关

在开始前需要准备如下：

1. github账号

#### 域名（可选）：

在国内任意平台可以免费注册一年期.cn域名，只需要提交ICP备案即可。（技巧是选择那些可以试用云服务的平台，因为平台帮助备案需要你在平台有除了域名之外的资产，一般等待两周左右即可正常解析域名。

#### 使用cloudflare服务：

若为自行购买的.cn域名可以将域名托管到cloudflare，在相应购买域名的平台中修改域名dns为cloudflare提供的dns即可。

## 开始

##### CLOUDFLARE - 部署 git-gateway4cloudflare（可以跳过直接使用github登录而不是git-gateway，请自行搜索配置方法）

使用github账户登录cloudflare，绑定银行卡或paypal账户即可使用cloudflare worker服务。

在 [Personal Access Tokens (Classic) ](https://github.com/settings/tokens) 获取 Personal access tokens (classic)，一定要给与repo的读写权限！获得api后立刻记录下来。

使用如下方式部署git-gateway4cloudflare：

```bash
git clone https://github.com/LinStuGit/git-gateway4cloudflare.git

cd git-gateway4cloudflare

# 1. 安装依赖
npm install

# 2. 配置环境变量
npx wrangler secret put ADMIN_PASSWORD
npx wrangler secret put GITHUB_PAT
npx wrangler secret put COMMITTER_NAME
npx wrangler secret put COMMITTER_EMAIL

# 3. 部署
npx wrangler login
npx wrangler deploy
```

记录下auth服务的地址，用于配置decap-cms。

##### GITHUB

创建github仓库并clone到本地，注意github ssh key是否正确并使用ssh方式克隆。同时开始前系统应有nodejs和npm。

```bash
# 克隆
git clone git@github.com:LinStuGit/hexo.git

cd hexo

npm install hexo-cli -g

# 初始化hexo
hexo init

# 编辑进行一些适当配置
nano _config.yml
# 特别的，找到skip_render:这一行，添加admin白名单，为decap-cms配置作准备：
# skip_render: admin/**/*
```

这时hexo基本框架就已经搭建好了。这时commit并push整个仓库，现在已经可以在vercel上部署hexo了。

##### VERCEL

打开 [vercel.com](https://vercel.com) ，使用github登录，点击Add New - Project。 在 Import Git Repository 选项卡中点击刚才创建的仓库，然后单击Deploy即可。部署成功后可在Dashboard页面看到Domains，即为网站域名。

##### DECAP-CMS

现在进行decap-cms的配置：

```bash
cd source

mkdir admin     # cms
mkdir resources # 用于保存媒体资源

cd admin

touch index.html

touch config.yml
```

其中 index.html内容如下:

```html
<!doctype html>
<html>
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta name="robots" content="noindex" />
  <title>博客管理</title>
</head>
<body>
  <script src="https://cdn.jsdelivr.net/npm/decap-cms@3.10.1/dist/decap-cms.min.js"></script>
</body>
</html>
```

config.yml内容如下（该配置仅适用于git-gateway4cloudflare，其他配置请自行搜索）：

```yml
backend:
  name: git-gateway
  branch: master
  repo: LinStuGit/hexo
  base_url: https://auth.linthu.cn              # 自行搭建的git-gateway在cloudflare上的部署地址
  identity_url: https://auth.linthu.cn/identity
  gateway_url: https://auth.linthu.cn/git/github
  use_json_payload: true

  commit_messages:
    create: "CMS: 创建 {{collection}} {{slug}}"
    update: "CMS: 更新 {{collection}} {{slug}}"
    delete: "CMS: 删除 {{collection}} {{slug}}"
    uploadMedia: "CMS: 上传媒体文件 {{path}}"
    deleteMedia: "CMS: 删除媒体文件 {{path}}"

local_backend: true  # 允许本地开发时使用

site_url: https://lin.linthu.cn                # vercel的部署地址
display_url: https://lin.linthu.cn             # 同上

media_folder: "source/resources"
public_folder: "/resources"

collections:
  - name: "posts"
    label: "文章"
    label_singular: "文章"
    folder: "source/_posts"
    create: true
    slug: "{{year}}-{{month}}-{{day}}-{{slug}}"
    extension: md
    format: frontmatter
    
    editor:
      preview: true
    
    fields:
      - { label: "标题", name: "title", widget: "string", required: true }
      - { label: "发布日期", name: "date", widget: "datetime", format: "YYYY-MM-DD HH:mm:ss", required: true }
      - { label: "标签", name: "tags", widget: "list", default: [], required: false }
      - { label: "分类", name: "categories", widget: "list", default: [], required: false }
      - { label: "封面图", name: cover, widget: "image", required: false, media_folder: "source/images/uploads", public_folder: "/images/uploads" }
      - { label: "摘要", name: description, widget: "text", required: false }
      - { label: "置顶", name: sticky, widget: "number", default: 0, required: false }
      - { label: "草稿", name: draft, widget: "boolean", default: false, required: false }
      - { label: "内容", name: "body", widget: "markdown", required: true }

  - name: "pages"
    label: "页面"
    folder: "source/about"
    create: true
    slug: "{{slug}}"
    extension: md
    format: frontmatter
    
    fields:
      - { label: "内容", name: "body", widget: "markdown" }

  - name: "settings"
    label: "站点设置"
    editor:
      preview: false
    files:
      - file: "_config.yml"
        label: "Hexo 配置"
        name: "hexo_config"
        fields:
          - { label: "站点标题", name: "title", widget: "string" }
          - { label: "副标题", name: "subtitle", widget: "string" }
          - { label: "作者", name: "author", widget: "string" }
          - { label: "语言", name: "language", widget: "string" }
```

commit并push。

现在已经可以通过访问网页的/admin使用cms系统了。

玩得愉快！
